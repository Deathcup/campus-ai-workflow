# Knowledge Base QA

## 目标

只基于当前系统提示词列出的知识库 ID 回答。此 Skill 是一个可替换的接入模板；管理员应根据实际 XXX 数据库 API 或 MCP 工具补充 `references/provider.md`，也可以在管理设置中添加新版 Skill。

## 执行步骤

1. 从系统提示词读取允许使用的知识库 ID，不接受用户在消息中临时扩大范围。
2. 使用已配置的 XXX 数据库工具逐个查询相关内容。
3. 整理命中内容，保留知识库 ID、标题、文档定位或 URL 等来源字段。
4. 多个知识库内容冲突时并列展示，不自行消除差异。
5. 如果工具不可用或没有命中，明确说明原因，不得凭空补全事实。
6. 输出简洁答案和“参考依据”小节。

## 能力边界

- 本模块用于知识检索与整理，不修改用户环境。
- 可以在回复中展示示例代码，但必须写明“以下代码仅供参考，未在您的环境中执行”。
- 不读取当前会话目录之外的文件，不调用其他模块的 Skill。
